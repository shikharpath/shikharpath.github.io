To publish free using GitHub Pages:
1. Sign in to GitHub and create a new public repository named shikharpathak.github.io
2. Upload index.html to the repository's root.
3. Open Settings → Pages. Select Deploy from a branch, choose main and /(root), then Save.
4. After GitHub finishes publishing, the site should be available at:
   https://shikharpathak.github.io/
